## Prerequisites

- A WhatsRB Cloud account with an API key ([Dashboard](https://whatsrb.com/dashboard))
- A connected WhatsApp Business Account
- A webhook endpoint (use [webhook.site](https://webhook.site) for testing)

## 1. Get your API key

Log in to the [WhatsRB Dashboard](https://whatsrb.com/dashboard) and navigate to **API Keys**. Create a new key — it starts with `wrb_live_`.

## 2. Register a webhook endpoint

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X POST https://whatsrb.com/api/v1/webhooks \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "webhook": {
          "url": "https://your-webhook-url.com/whatsrb",
          "events": ["agent_run.completed", "agent_run.failed"]
        }
      }'
    ```
  </Tab>
  <Tab title="Ruby">
    ```ruby
    require "whatsrb_cloud"

    WhatsrbCloud.configure { |c| c.api_key = "wrb_live_xxx" }
    client = WhatsrbCloud::Client.new

    client.webhooks.create(
      url: "https://your-webhook-url.com/whatsrb",
      events: ["agent_run.completed", "agent_run.failed"]
    )
    ```
  </Tab>
</Tabs>

## 3. Create an agent

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X POST https://whatsrb.com/api/v1/agents \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "agent": {
          "name": "Support Agent",
          "business_account_id": "YOUR_BA_ID",
          "system_prompt": "You are a customer support agent for an e-commerce store. Classify requests and extract relevant fields.",
          "auto_run_inbound": true,
          "allowed_actions": [
            "support.refund.process",
            "support.ticket.create",
            "support.order.status"
          ],
          "payload_schema": [
            { "name": "order_id", "field_type": "text", "required": true },
            { "name": "reason", "field_type": "text", "required": true },
            { "name": "amount", "field_type": "number", "required": false }
          ]
        }
      }'
    ```
  </Tab>
  <Tab title="Ruby">
    ```ruby
    agent = client.agents.create(
      name: "Support Agent",
      business_account_id: "YOUR_BA_ID",
      system_prompt: "You are a customer support agent for an e-commerce store. Classify requests and extract relevant fields.",
      auto_run_inbound: true,
      allowed_actions: [
        "support.refund.process",
        "support.ticket.create",
        "support.order.status"
      ],
      payload_schema: [
        { name: "order_id", field_type: "text", required: true },
        { name: "reason", field_type: "text", required: true },
        { name: "amount", field_type: "number", required: false }
      ]
    )
    ```
  </Tab>
</Tabs>

## 4. Send a test message

Send a WhatsApp message to your connected business number:

> *"My order #ORD-1234 arrived broken, I want a refund of $49.90"*

## 5. Receive the webhook

Within seconds, your webhook endpoint receives:

```json
{
  "event": "agent_run.completed",
  "data": {
    "run_id": "run_abc123",
    "agent_id": "agt_def456",
    "status": "completed",
    "from": "33612345678",
    "output": {
      "intent": "refund_request",
      "confidence": 0.95,
      "actions": [
        {
          "type": "support.refund.process",
          "payload": {
            "order_id": "ORD-1234",
            "reason": "Product arrived broken",
            "amount": 49.90
          }
        }
      ],
      "language": "en",
      "suggested_reply": "I'm sorry about that! I'll process your refund of $49.90 for order #ORD-1234 right away.",
      "analysis_summary": "Customer requests refund for broken product"
    },
    "tokens": { "input": 850, "output": 120 },
    "duration_ms": 450
  }
}
```

The `type` is guaranteed to be one of your `allowed_actions`. The `payload` fields match your `payload_schema`. Your backend can safely parse and execute.

## 6. Handle it in your backend

```ruby
# Your webhook handler
case action["type"]
when "support.refund.process"
  Refunds::Process.call(
    order_id: action.dig("payload", "order_id"),
    amount: action.dig("payload", "amount"),
    reason: action.dig("payload", "reason")
  )
when "support.ticket.create"
  Tickets::Create.call(action["payload"])
when "support.order.status"
  Orders::CheckStatus.call(action["payload"])
end
```
