## Prerequisites

- A WhatsRB Cloud account with an API key
- A connected WhatsApp Business Account

## 1. Get your API key

Log in to the [WhatsRB Dashboard](https://whatsrb.com/dashboard) and navigate to **API Keys**. Create a new key and copy it.

## 2. Send a message

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X POST https://whatsrb.com/api/v1/business_accounts/:id/messages \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "to": "+33612345678",
        "type": "text",
        "text": "Hello from WhatsRB!"
      }'
    ```
  </Tab>
  <Tab title="Ruby">
    ```ruby
    require "whatsrb_cloud"

    WhatsrbCloud.configure do |c|
      c.api_key = "wrb_live_xxx"
    end

    client  = WhatsrbCloud::Client.new
    account = client.business_accounts.list.data.first

    account.send_text(
      to: "+33612345678",
      text: "Hello from WhatsRB!"
    )
    ```
  </Tab>
</Tabs>

## 3. Check delivery status

Message statuses are delivered via [webhooks](/guides/webhooks). You'll receive events for `sent`, `delivered`, `read`, and `failed`.
