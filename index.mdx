## What is WhatsRB Cloud?

WhatsRB Cloud is a hosted platform that lets you send WhatsApp messages, manage templates, and handle webhooks through a simple REST API and Ruby SDK.

We handle Meta tokens, scaling, and reliability — you just send messages.

## Key Features

- **Official WhatsApp API** — No unofficial workarounds. Full Business API compliance.
- **Ruby SDK** — Idiomatic Ruby client with built-in error handling.
- **REST API** — Use any language with standard HTTP calls.
- **Template Management** — Create, sync, and send pre-approved templates.
- **Developer Logs** — Full request/response logs and delivery tracking.
- **Webhooks** — Real-time events for messages, statuses, and errors.
