## Authentication

Every request must include your API key as a Bearer token:

```bash
Authorization: Bearer wrb_live_xxxxxxxxxxxxx
```

Generate your key from the [WhatsRB Dashboard](https://whatsrb.com/dashboard) under **Settings → API Keys**.

<Warning>
  Keep your API key secret. Never expose it in client-side code or public repositories.
</Warning>

## Response format

All responses return JSON. Successful responses wrap data in a `data` key:

```json
{
  "data": {
    "id": "agt_abc123",
    "name": "Support Agent",
    "model": "gpt-4o-mini",
    "active": true,
    "allowed_actions": ["support.refund.process", "support.ticket.create"]
  }
}
```

List endpoints include a `meta` key with pagination info:

```json
{
  "data": [...],
  "meta": {
    "total": 42,
    "plan_limit": 10
  }
}
```

## Error format

Errors return a JSON object with a human-readable `error` key:

```json
{
  "error": "Business account not found"
}
```

| Status | Meaning |
|--------|---------|
| `400` | Bad request — invalid parameters |
| `401` | Unauthorized — missing or invalid API key |
| `403` | Forbidden — plan limit reached |
| `404` | Not found |
| `422` | Validation error |
| `429` | Rate limited |
| `5xx` | Server error |
