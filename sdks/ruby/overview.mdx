## Installation

```ruby
# Gemfile
gem "whatsrb_cloud", git: "https://gitlab.com/whatsrb/sdk-ruby.git"
```

```bash
bundle install
```

## Setup

```ruby
require "whatsrb_cloud"

WhatsrbCloud.configure do |c|
  c.api_key = ENV["WHATSRB_API_KEY"]
end

client = WhatsrbCloud::Client.new
```

Or pass the key directly:

```ruby
client = WhatsrbCloud::Client.new(api_key: "wrb_live_xxx")
```

## Quick example

```ruby
# Create an agent
agent = client.agents.create(
  name: "Support Agent",
  system_prompt: "Handle customer support requests.",
  allowed_actions: ["support.refund.process", "support.ticket.create"]
)

# Run it
run = agent.run(input: "I want a refund for order ORD-1234")
run.refresh  # poll for completion

run.actions  # => [{ "type" => "support.refund.process", "payload" => { "order_id" => "ORD-1234" } }]

# Send a message via Business API
account = client.business_accounts.list.data.first
account.send_text(to: "+33612345678", text: run.suggested_reply)
```

## Error handling

All SDK methods raise typed exceptions:

```ruby
begin
  account.send_text(to: "+33612345678", text: "Hello!")
rescue WhatsrbCloud::AuthenticationError => e
  # Invalid API key
rescue WhatsrbCloud::NotFoundError => e
  # Account not found
rescue WhatsrbCloud::RateLimitError => e
  puts "Retry after #{e.retry_after}s"
rescue WhatsrbCloud::ValidationError => e
  # Invalid parameters
rescue WhatsrbCloud::ServerError => e
  # 5xx from the API
rescue WhatsrbCloud::Error => e
  # Base class for all SDK errors
end
```

| Exception | HTTP status |
|-----------|------------|
| `AuthenticationError` | 401 |
| `ForbiddenError` | 403 |
| `NotFoundError` | 404 |
| `ConflictError` | 409 |
| `ValidationError` | 422 |
| `RateLimitError` | 429 |
| `ServerError` | 5xx |
