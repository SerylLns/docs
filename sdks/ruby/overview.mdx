## Overview

The `whatsrb_cloud` gem is an idiomatic Ruby client for the WhatsRB Cloud API. It wraps all REST endpoints with a clean, chainable interface.

```ruby
client = WhatsrbCloud::Client.new(api_key: "wrb_live_xxx")
account = client.business_accounts.list.data.first

account.send_text(to: "+33612345678", text: "Hello!")
```

## Requirements

- Ruby 3.1+
- Works with Rails, Sinatra, or plain Ruby
