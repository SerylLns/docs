## List agents

```ruby
result.each { |agent| puts agent.name }  # List is Enumerable

```

## Create an agent

```ruby
agent = client.agents.create(
  name: "Hotel Concierge",
  system_prompt: "You are a hotel operations agent...",
  business_account_id: "acc_01hx..."
)

agent.id     # => "agt_01hx..."
agent.name   # => "Hotel Concierge"
agent.status # => "active"
```

### With structured fields

Define `payload_schema` to enforce specific fields in the AI output payload:

```ruby
agent = client.agents.create(
  name: "Hotel Concierge",
  system_prompt: "Extract structured tasks from hotel guest messages.",
  payload_schema: [
    { name: "room_number", field_type: "text", required: true },
    { name: "description", field_type: "text", required: true },
    { name: "due_at", field_type: "datetime", required: false },
    { name: "priority", field_type: "text", required: false }
  ]
)

agent.payload_schema  # => [{ "name" => "room_number", "field_type" => "text", "required" => true }, ...]
```

Available field types: `text`, `number`, `boolean`, `date`, `time`, `datetime`. Max 10 fields.

### With allowed action types

By default, the AI can return any action type (free-form). Set `allowed_actions` to constrain it to a specific list — the AI **can only return values from this list**.

```ruby
agent = client.agents.create(
  name: "Support Agent",
  system_prompt: "Handle customer support requests.",
  allowed_actions: [
    "support.refund.process",
    "support.ticket.create",
    "support.escalation.request"
  ]
)

agent.allowed_actions  # => ["support.refund.process", "support.ticket.create", ...]
```

Format: `domain.resource.action` (snake_case, 3 segments). Max 10 action types.

When a run completes, every action's `type` is guaranteed to be in this list:

```ruby
run = agent.run(input: { last_message: "I want a refund for order #1234" })

run.actions.each do |action|
  case action["type"]
  when "support.refund.process"
    Refunds::Process.call(action["payload"])
  when "support.ticket.create"
    Tickets::Create.call(action["payload"])
  when "support.escalation.request"
    Escalations::Notify.call(action["payload"])
  end
end
```

<Tip>
  Without `allowed_actions`, the AI invents action types freely — useful for prototyping but unpredictable in production. Add constraints once you know your action types.
</Tip>

<Note>
  `required` instructs the AI to always fill the field — it does not guarantee a value.
  Always validate on your end before processing actions.
</Note>

## Run an agent

Creates a run and **returns immediately**. The run is processed asynchronously — poll with `refresh` or listen via webhook.

```ruby
# String input (auto-wrapped as last_message)
run = agent.run(input: "Clean room 204 tomorrow at 8")

# Hash input (full control)
run = agent.run(input: {
  last_message: "Clean room 204 tomorrow at 8",
  recent_messages: ["Hi, I have a request"]
})

run.status  # => "pending"
```

Poll for completion:

```ruby
run.refresh
run.completed?      # => true
run.intent          # => "task_extraction"
run.confidence      # => 0.95
run.actions         # => [{ "type" => "hospitality.room_service.request", "payload" => { ... } }]
run.suggested_reply # => "I'll arrange cleaning for room 204 tomorrow at 8am."
run.context_summary # => "Guest requested room 204 cleaning for tomorrow 8am."
```

## Dispatch actions with a registry

Use an `ActionRegistry` to route agent actions to your service objects:

```ruby
registry = WhatsrbCloud::ActionRegistry.new

registry.register("create_task") do |action|
  Task.create!(
    description: action["description"],
    room_number: action["room_number"],
    priority: action["priority"]
  )
end

registry.register("create_ticket") do |action|
  Ticket.create!(message: action["message"])
end

# Dispatch all actions from a completed run
run = agent.run(input: { last_message: "Fix the AC in room 107" })
run.dispatch(registry)
```

See [Registries](/sdks/ruby/registries) for the full guide.

## Agent attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | String | Agent ID (`agt_...`) |
| `name` | String | Agent name |
| `description` | String | Agent description |
| `model` | String | Model used (`gpt-4o-mini`) |
| `temperature` | Float | LLM temperature |
| `max_tokens` | Integer | Max output tokens |
| `active` | Boolean | Whether agent is active |
| `auto_run_inbound` | Boolean | Auto-process inbound messages |
| `debounce_seconds` | Integer | Batch window for rapid messages |
| `context_ttl_minutes` | Integer | Conversation context TTL (default 60) |
| `business_account_id` | String | Linked business account |
| `allowed_actions` | Array | Allowed action types (empty = free-form) |
| `payload_schema` | Array | Structured field definitions |
| `active?` | Boolean | Whether agent is active |

## AgentRun attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | String | Run ID (`run_...`) |
| `agent_id` | String | Parent agent ID |
| `status` | String | `pending`, `running`, `completed`, `failed` |
| `triggered_by` | String | `api`, `auto_inbound` |
| `output` | Hash | Full agent output |
| `error_message` | String | Error message if failed |
| `model_used` | String | LLM model used |
| `input_tokens` | Integer | Tokens consumed |
| `output_tokens` | Integer | Tokens generated |
| `latency_ms` | Integer | LLM response latency |
| `duration_ms` | Integer | Total run duration |
| `intent` | String | Shortcut for `output["intent"]` |
| `confidence` | Float | Shortcut for `output["confidence"]` |
| `actions` | Array | Shortcut for `output["actions"]` |
| `suggested_reply` | String | Suggested reply in customer's language |
| `context_summary` | String | Conversation state for continuity |
| `pending?` | Boolean | Status is pending |
| `completed?` | Boolean | Status is completed |
| `failed?` | Boolean | Status is failed |
