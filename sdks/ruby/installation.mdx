---
title: Installation
description: Install the WhatsRB Cloud Ruby SDK.
---

## Bundler (recommended)

Add to your `Gemfile`:

```ruby
gem "whatsrb_cloud", git: "https://github.com/SerylLns/whatsrb-sdk", glob: "ruby/*.gemspec"
```

Then run:

```bash
bundle install
```

## Verify installation

```ruby
require "whatsrb_cloud"
puts WhatsrbCloud::VERSION
```
