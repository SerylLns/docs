---
title: Installation
description: Install the WhatsRB Cloud Ruby SDK.
---

## Bundler (recommended)

Add to your `Gemfile`:

```ruby
gem "whatsrb_cloud", git: "https://gitlab.com/whatsrb/sdk-ruby.git"
```

Then run:

```bash
bundle install
```

## Verify installation

```ruby
require "whatsrb_cloud"
puts WhatsrbCloud::VERSION
```
